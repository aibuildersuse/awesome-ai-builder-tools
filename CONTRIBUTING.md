# Contribution guidelines

Thanks for helping improve this list.

- **One tool per pull request.** Add it to the section that fits its main job.
- **Format:** `- [Name](official-url) - Short, factual description ending in a period.`
- **Must ship today:** the tool needs to be publicly available, not a waitlist.
- **Facts only:** no marketing superlatives, and no pricing claims you can't link to on the vendor's site.
- **Use the official URL:** no affiliate or referral links.
- **Disclose ties:** if you work for the company behind the tool, say so in the PR. That doesn't disqualify it.
- Corrections (renames, dead links, changed facts) are always welcome.

The README is generated from the [AIBuildersUse](https://aibuildersuse.com) dataset, so maintainers apply accepted suggestions there and regenerate the file.
